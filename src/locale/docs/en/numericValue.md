**Numeric Value** node is a **processing-type node (converter)** used to transform symbolic data into quantitative data. It acts as a translator that takes a symbol (or a list of symbols from a **Symbolic Pool**) and assigns a specific numerical value to each based on a **dictionary defined by the user**.

This node is essential for converting qualitative categories (such as "Gold", "Silver", "Bronze") into values that can be processed by mathematical operators, magnitude comparators, or statistical nodes.

* **Type:** Processing / Converter
* **Function:** Assigns and sums numerical values to corresponding symbols.
* **Input:** A single symbolic value or a list of symbols (pool).
* **Output:** Total numerical value (sum of all processed symbol values).

---

### **Properties**

#### **Node ID**

* **Type:** Text
* **Default:** Random ID
* **Function:** Unique identifier for the node.

#### **Status**

* **Type:** `Finished` | `Idle` | `Error` | `Waiting for Input`
* **Default:** `Idle`
* **Function:** Indicates the current state of the node.

#### **Name**

* **Type:** Text
* **Default:** Numeric Value
* **Function:** Name displayed on the modeling canvas.

#### **Value Dictionary (From-To)**

* **Type:** Symbol and Value Tuple (Text | Decimal/Integer Number)
* **Symbol (Text):** The expected input symbol name.
* **Value (Number):** The numerical value this symbol represents.


* **Default:** `["A", 1]`
* **Function:** Maps how much each symbol is worth for the final calculation.

#### **Missing Symbol Treatment**

* **Behavior:** Always `0`
* **Function:** If the node receives a symbol that is not present in the **Value Dictionary**, the value assigned to it will automatically be **zero**, ensuring the calculation continues without errors.

---

### **Notes**

* **Automatic Summation:** If the node receives a list of symbols (a pool), it will automatically output the total sum of all corresponding values.
* **Compatibility:** The output result (number) is fully compatible with **Mathematical Operators**, **Comparators**, and **Charts**.
* **Resilience:** Since the missing symbol treatment is fixed at 0, the node ensures the processing chain does not break even if the source generates unexpected symbols.
